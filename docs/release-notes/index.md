## Feature Categories

Features are organized into the following categories:

- **Architecture** - Platform upgrades and system design changes
- **Development** - API changes, OSGi factories, plugin development
- **Functional** - Business features (accounting, inventory, manufacturing)
- **Security** - Authentication, authorization, password policies
- **Technical** - Database, configuration, performance improvements
- **User Experience** - UI improvements, navigation, workflow enhancements
