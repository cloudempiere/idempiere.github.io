# Version 1.0 Release Notes

**Released:** 2012 · **Focus:** Foundation Release

The inaugural release of iDempiere, forking from ADempiere to embrace OSGi architecture and modern web technologies.

**Key Highlights:**
- OSGi-based plugin architecture
- ZK web interface improvements
- Enhanced security with password rules and user locking
- 2Pack packaging system revamp
