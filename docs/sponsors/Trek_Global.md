# Trek Global

[Trek Global](https://www.trekglobal.com/) is an iDempiere implementation partner and active contributor to the iDempiere project.

## Website

- **Website:** [https://www.trekglobal.com/](https://www.trekglobal.com/)

## Contributions

Trek Global has sponsored numerous features in iDempiere, including:

- Accounting Viewer Improvements
- Security enhancements (password rules, user locking, role inheritance)
- User experience improvements (menu, login, forms)
- Technical infrastructure (distributed cache, storage providers)
- And many more...

## About

Trek Global provides enterprise consulting, implementation, and support services for iDempiere ERP.
